# 平衡校验提示词

## 触发
```
@balance-check 校验 [story_one|story_more|task|all]
```

## 检查项

### story_one.gd（普通事件）
- [ ] 每事件首选项 `leave: true` 且全 0
- [ ] 灵石 ∈ [-50, 150]
- [ ] 声望 ∈ [-30, 30]
- [ ] 寿命 ∈ [-7, -1]
- [ ] cultivation = 0（所有选项）
- [ ] 选项数 = 4
- [ ] qiyun > 0 仅出现在"重要 NPC 击杀/降伏"且单事件 ≤ 1 选项
- [ ] 含 ≥ 1 灰色选项（声望 -15 以上）
- [ ] 题材非全战斗/探宝

### story_more.gd（隐藏事件）
- [ ] 灵石 ∈ [80, 300]
- [ ] 声望 ∈ [15, 80]
- [ ] 寿命 ∈ [-4, -1]
- [ ] cultivation = 0
- [ ] 选项数 ∈ [2, 4]
- [ ] 含道具奖励事件占比 ≥ 50%

### task.gd
- [ ] 每任务七档齐全
- [ ] SSS 灵石 ≤ 850
- [ ] cultivation = 0
- [ ] 七档梯度合理（无倒挂）

## 产出
- 违规列表（文件:行号 + 字段 + 实际值 + 期望）
- 修复建议
- 不直接改代码，先报告
