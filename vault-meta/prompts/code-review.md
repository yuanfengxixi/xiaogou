# 代码审查提示词

## 触发
```
@code-review [文件名 | commit hash | "uncommitted"]
```

## 审查重点

### 设计一致性
- 实现是否符合 design/gdd 中对应文档
- 数值红线（[[../HOME#🔥-数值红线速查]]）
- CLAUDE.md "已确定的设计决策"9 条是否被破坏

### 代码质量（GDScript）
- 单文件状态机原则（game.gd 为唯一驱动）
- 文件职责边界（[[../../CLAUDE]] §文件职责）
- 命名一致：snake_case 函数 / SCREAMING 常量
- UI 纯代码驱动，不引入 .tscn 散件

### 安全检查
- 数值边界保护（如集市双重灵石检查）
- 状态转移完整（无死循环、无悬挂状态）
- 寿命归零判定（每行动后检查）

## 产出格式
```
[严重] 文件:行号 — 问题 — 建议
[警告] 文件:行号 — 问题 — 建议
[提示] 文件:行号 — 问题 — 建议
```
