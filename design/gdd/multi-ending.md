# 多路线终局系统

## 1. Overview

沙盒修仙世界没有单一胜利条件。每个玩家的结局都是自己这一生的真实回响——飞升、枭雄、魔尊、隐士、凡人、横死皆是合法结局。终局不是"胜/败"判定，而是一段生命的总结。系统根据玩家的境界、声望、势力、成就、关系、死因等多维状态，生成与其经历契合的结局呈现：生平回顾、世界反应、遗泽留存、法号/绰号归档。

## 2. Player Fantasy

- 结局不是随机的，是你这一生真实轨迹的映射
- 死亡是句点，不是失败——横死的凡人与飞升的仙人都完成了一次完整的修仙
- 看到世界对你离去的反应，感受"我真的在这个世界活过"
- 每次重玩探索不同的人生形态，而不是重刷同一个结局

## 3. Detailed Rules

### 终局触发条件

| 触发 | 说明 |
|------|------|
| 飞升 | realm 达到5，渡过飞升考验 |
| 寿尽 | lifespan ≤ 0，自然或强制 |
| 战死 | 对抗失败（同境界败或差距过大） |
| 天劫陨落 | 突破天劫失败 |
| 突破身死 | 突破过程中死亡（心魔、天劫、敌人干扰） |
| 背叛陨落 | 信任之人所害 |
| 根基尽毁终老 | 根基损伤无法修复，寿尽于现有境界 |
| 主动归隐 | 玩家选择退出修仙路，等待寿尽 |
| 心魔缠身而死 | 心志归零后状态恶化至死 |

### 终局分类维度

终局呈现不按固定分支脚本，由以下维度组合生成：

**境界维度**
- 飞升
- 化神期（顶端存在）
- 元婴/金丹（中坚修士）
- 筑基（入门修士）
- 练气（始终未入门）

**声望维度**
- 极正声望：正道圣人/前辈
- 极负声望：魔道巨头/祸患
- 中间态：无名散修

**势力维度**
- 某势力领袖/掌门
- 势力核心成员
- 独立散修
- 势力公敌

**成就维度**
- 杀死某命名NPC
- 毁掉/建立某势力
- 收了几位弟子
- 留下传承/典籍
- 促成或阻止某世界大事

**关系维度**
- 亲密关系（道侣、挚友、门徒）的最终状态
- 仇敌的最终状态

**死因维度**
- 由终局触发条件决定

### 终局呈现

**生平回顾**
- 关键事件按时间顺序呈现
- 重要选择与转折点
- 遇到的主要NPC及其最终结局

**世界反应**
- 正道/魔道/中立NPC对玩家死讯的评价
- 相关势力的官方态度
- 江湖流传的评说

**遗泽留存（本局内）**
- 玩家在世界中留下的痕迹——杀的人、建的势力、收的徒弟
- 由于无跨局继承，这些痕迹仅作为本局结局的展示

**法号/绰号**
- 根据生平自动或半自动生成称号
- 归档进称号图鉴，作为历代轮回的记录

### 无评级原则

- 结局不按优劣排序
- 飞升不是"最好"的结局，横死也不是"最差"的
- 每个结局以独立视角呈现，尊重玩家的选择
- 玩家可自行判断这一世是否满意

### 主动归隐机制

- 高龄或心境变化时，玩家可选择退出修仙舞台
- 进入"闭门不出"状态，时间快速推进至寿尽
- 归隐期间不触发主动事件，但仍可能被动卷入（仇敌登门）
- 归隐是有意识的选择，而非被迫

## 4. Formulas

生平回顾生成逻辑、评价文字选择逻辑待设计阶段确定。
框架方向：
- 根据关键成就标签匹配文字模板
- 声望阈值决定NPC评价倾向
- 势力关系决定哪些势力发声

## 5. Edge Cases

- **早夭**：练气期就死亡，生平回顾依然完整，只是内容极短
- **多成就冲突**：同时满足"正道圣人"与"魔道巨头"条件时，以最终声望为准
- **无名终老**：既无成就也无站队的玩家，仍有独立的"平凡一生"结局呈现
- **飞升后余波**：玩家飞升离开，但本局已发生的事件继续影响世界（在本局结局呈现中体现）
- **孤独死亡**：无任何关系的玩家死亡，结局重点放在世界对这个"陌生人"的冷漠或忽视上

## 6. Dependencies

- **上游**：所有子系统（修炼、权力、突破、心志、经济、历练事件、任务、宗门均贡献结局输入）
- **下游**：称号图鉴系统（接收法号/绰号归档）
- **状态机**：终局状态为游戏结束态，不可返回行动

## 7. Tuning Knobs

- 结局文字模板数量与分类粒度
- 声望/境界/势力阈值对应的结局分类
- 生平回顾事件筛选规则
- 世界反应NPC数量与发声权重
- 称号生成规则

## 8. Acceptance Criteria

- [ ] 所有触发条件均对应完整结局呈现
- [ ] 结局内容根据玩家实际经历生成，非固定脚本
- [ ] 生平回顾包含关键事件与转折点
- [ ] 世界反应文字与玩家声望/势力关系匹配
- [ ] 法号/绰号归入称号图鉴
- [ ] 飞升与横死获得同等呈现质量，无优劣评级
- [ ] 主动归隐可触发并进入寿尽结算
