# 历练事件系统 — Story System GDD

**版本**：1.0
**最后更新**：2026-05-02
**适用文件**：`story_one.gd`（普通历练）、`story_more.gd`（隐藏机缘，本 GDD 仅引用 schema 部分）
**关联系统**：psychology-distraction.md（mind 机制）、cultivation-system.md（修为公式）、breakthrough-minigame.md（突破公式）

---

## 1. Overview

历练事件是玩家"出门"动作触发的随机叙事节点，是游戏外部经济（灵石/道具/气运）与外部声誉（prestige）的主要来源，也是游戏世界观与角色互动的主要承载层。每次出门触发 1 条事件，玩家从 4 个选项中做出唯一选择，结果即时结算。普通历练 (`type: "adventure"`) 是江湖日常；隐藏机缘 (`type: "hidden"`) 是命运转折，多轮 score 制结算（既有，本 GDD 不重写）。

本 GDD 的核心目标：建立一份权威的事件书写规范与 schema 标准，约束所有未来 `story_one.gd` 内容产出，保证题材多样性、写作风格一致性、数值边界可控。

---

## 2. Player Fantasy

玩家是一名**穿越修仙世界的普通人**，无背景、无天赋、无气运。出门历练时，玩家应感到：

- **自主权**：每次事件都可"转身离去"，不被叙事强迫
- **选择有重量**：4 个选项各有性格，灰色选项的暴利与正义选项的清贫构成真实博弈
- **世界鲜活**：修仙不是天天打架，柴米油盐、师门人情、风花雪月才是江湖底色
- **务实代入**：主角内心冷静、计较得失、偶尔自嘲，不喊口号、不当救世主
- **机缘稀薄但存在**：极少数事件能击杀重要 NPC 提升气运，玩家会记住"那一次斩了血手罗刹"

## 3. Detailed Rules

### 3.1 事件触发流程

1. 玩家在 FREE 状态点击"出门历练"（`_on_practice` → `_practice_active = true`）
2. `_show_story()` 从 `StoryOne.EVENTS` 池随机抽取 1 条（隐藏概率根据 prestige + qiyun 计算）
3. 玩家从 4 个选项中选 1 个
4. 选中"离开"（`leave: true`）→ 跳过 `pass_time`，不恢复 mind，回 FREE，可立即再触发历练
5. 选中其他 → `pass_time(N)` + 应用 gold/prestige/lifespan/item/qiyun 增量 → `complete_practice()`（mind 恢复 + mind_max+0.25）→ FREE

### 3.2 选项数量与离开规则

- **固定 4 选项**。**渲染层 shuffle 全部选项位置**（含离开），每次进入屏幕顺序随机
- 离开选项靠 `leave: true` 字段识别（位置不固定，玩家从文本判断哪一个是"转身/退避"语义）
- 离开选项 schema 数值字段完全归零
- 其余 3 个为"实质行动"选项，至少 1 个是灰色选项（利己损人）
- 离开选项不消耗 mind、不消耗时间、不掉声望、无任何收益
- 离开选项可被玩家"刷历练池"利用（一直离开直到出现想要的事件）— 接受此 UX 取舍，因 mind 不恢复，玩家无法靠刷 leave 累积闭关收益
- **写作约束**：离开选项的 `text` 必须语义清晰（"转身离去 / 不涉此事 / 远离是非 / 退避三舍" 等），玩家通过文本判断而非位置判断

### 3.3 事件 schema

```
{
  "type": "adventure",
  "id": "ad_001",                       // 唯一编号，便于跨文档引用
  "topic": ["combat"] | ["slice", "gray"],  // 题材标签，单/复合
  "suggested_realm": 0,                 // 推荐境界，影响触发权重
  "text": "...",                        // 80~180 字情境
  "choices": [
    { "leave": true, "text": "...", "result": "...",
      "gold": 0, "prestige": 0, "lifespan": 0,
      "item": "", "qiyun": 0, "cultivation": 0 },
    { "text": "...", "result": "...",
      "gold": int, "prestige": int, "lifespan": int,
      "item": "...", "qiyun": int, "cultivation": 0 },
    { ... },
    { ... }
  ]
}
```

可选字段：`min_realm`（实质选项的境界门槛）、`low_realm_result`（不达门槛替代文本）、`low_realm_lifespan`（不达门槛寿命惩罚）。

### 3.4 数值字段定义

| 字段 | 类型 | 范围 | 说明 |
|---|---|---|---|
| `text` | string | 8~20 字 | 选项标签，体现主角性格 |
| `result` | string | ≥ 2 句 / 40~120 字 | 结果叙述，因果链 |
| `gold` | int | -50 ~ +150 | 灵石变动，正义选项不超过灰色选项 |
| `prestige` | int | -30 ~ +30 | 声望，灰色选项 ≤ -15 |
| `lifespan` | int | -1 ~ -7 | 寿命消耗（仅 leave 可为 0） |
| `item` | string | items.gd 注册 id | 道具名，无掉落填 `""` |
| `qiyun` | int | 0 ~ +5 | **NEW** — 仅"击杀重要 NPC"选项可 > 0 |
| `cultivation` | int | 固定 0 | 永远 0，保留兼容字段 |
| `leave` | bool | 仅离开选项 = true | game.gd 检测，跳过 pass_time |

### 3.5 道具掉落白名单

仅以下 5 类（必须在 `items.gd` ITEM_META 注册才可写入 `item` 字段）：

1. **聚灵丹 1-5 阶**（按 suggested_realm 限发，不得跨阶）
2. **突破符 / 残缺破境符 1-5 阶**
3. **突破材料**：筑基丹 / 金丹 / 元婴珠 / 化神石（仅适配境界）
4. **功法**（5 阶）：用后 +talent_speed 永久
5. **气运丹**（3 阶）：用后 +talent_luck 永久

### 3.6 气运奖励规则

- `qiyun > 0` 仅出现在选项 result 文本明确"击杀/降伏/收服重要 NPC"语义时
- 单选项 `qiyun` 上限 +5
- 单事件最多 1 个选项给 qiyun
- "重要 NPC" 定义：在 result 文本中点名（绰号/法号/势力身份）的非杂兵敌人
- 气运转化为 `talent_luck` 永久增量；通过 `player.add_qiyun(n)` 写入

### 3.7 题材分布硬约束（按 30 事件总量）

| 题材 | topic 标签 | 比例 | 数量 |
|---|---|---|---|
| 战斗 | `combat` | ≤ 20% | ≤ 6 |
| 探宝/秘境 | `treasure` | ≤ 17% | ≤ 5 |
| 师门人情 | `sect` | ≥ 17% | ≥ 5 |
| 江湖见闻 | `rumor` | ≥ 13% | ≥ 4 |
| 生活趣事 | `slice` | ≥ 23% | ≥ 7（重头戏） |
| 灰色性质 | `gray` | ≥ 10% | ≥ 3（复合标签） |

**核心原则**：战斗 + 探宝合计封顶 11/30，剩余 19+ 必须为非战非宝。`gray` 是性质标签可与主标签复合（例：`["slice", "gray"]` = 灰色生活事）。

## 4. Writing Style — 写作风格规范

### 4.1 总基调

古典修仙 + 蛊真人方源式务实冷静。有文气不晦涩，克制不抒情，偶有反差幽默。主角是穿越者，遇事先想"这对我有什么用"，不喊口号、不表态、不当救世主。

### 4.2 情境描写（事件 `text` 段）

- 必有画面：场景、气味、声音、姿态至少出现 1 项
- 长度：80 ~ 180 字
- 信息要素必须三全：起因 + 当前局面 + 利益钩子（钱/名/物/恩怨）
- 反例："你遇到了一头野猪。"
- 正例："山道转角，一头浑身黑鬃的野猪精拦住去路，獠牙上还挂着上一个倒霉蛊修的碎布。村中悬赏三十灵石，已死两人。"

### 4.3 选项文字（`choice.text`）

- 长度：8 ~ 20 字，短促有力
- 体现主角性格：务实、冷静、偶尔自嘲
- 禁止抽象指令型："选择攻击" / "战斗" / "拒绝"
- 鼓励动作 + 心态："横剑挡前，硬碰硬看谁先垮"
- 灰色选项要"看上去合理"，不能露骨标榜恶意。例：「反正死无对证，把他袋子也摸了」高于「趁机抢劫」

**离开选项 5 套标准模板**（任选其一变体）：
1. 「这事不掺和，转身走人」
2. 「估摸不划算，闪人」
3. 「装作没看见，绕道」
4. 「点头致意，借故离开」
5. 「咳嗽一声，原路退回」

### 4.4 结果描写（`choice.result`）

- 长度：≥ 2 句，约 40 ~ 120 字
- 必有因果链：选择 → 过程一笔 → 结果落点
- 数值变化**禁止**直接报数字（"获得 50 灵石"），UI 自会渲染
- 用感性语言点到为止："约莫五十枚的分量" / "袋里多了几块沉甸甸的"
- 反例："你获得了 50 灵石。"
- 正例："野猪精被你一剑封喉，倒在血泊里。你从它颈下摸出一个皮囊，掂了掂，约莫五十枚的分量，村正还多塞了两块腊肉。"

### 4.5 负面结果

- 自嘲、无奈、轻描淡写，不让玩家挫败
- 禁止："你惨败而归，颜面尽失。" / "你失败了。"
- 推荐："你灰溜溜退出比武台，师兄们的笑声追在身后，倒也不是什么大事。"
- 受伤掉寿命要具体：摔了一跤、咳了两口血、被符火燎了眉毛——避免"重伤""濒死"绝对词

### 4.6 灰色选项（每事件至少 1 个）

- gold 收益必须 > 正义选项 gold（短期暴利）
- prestige ≤ -15（长期代价大，影响隐藏事件触发率）
- 不写道德说教式 result，让数字自己说话
- 反例："你良心不安，从此修为停滞。"
- 正例："你扛着布袋下山，灵石碰撞声很悦耳。师门那边的眼神，以后再说。"

### 4.7 江湖日常 / 生活气息

修仙不是天天大战。柴米油盐式小事同样有趣：怎么省灵石、怎么和师兄打交道、这事值不值得掺和。偶尔冒出大白话与修仙背景反差萌：

- "你盘算了一下，这笔买卖不划算。"
- "师兄说要借十灵石下月还，你想起他上次借的那五块也没还。"

### 4.8 重要 NPC 击杀（qiyun 选项专用）

- text 必须点名 NPC（绰号/法号/势力）："斩了「血手罗刹」"，禁止 "击杀强敌"
- result 须强调"气运转嫁"语义：
  > "那股阴沉的气运随血雾散去，你只觉额头一凉，似有什么东西落了下来。"
- 禁止滥用：仅 combat 题材且明确点名敌人时才有资格挂 qiyun

### 4.9 Anti-patterns 清单（写到一条直接打回）

1. 主角内心独白超过两句
2. 出现"主角"/"你"以外的二人称
3. 网络用语、现代俚语（"卧槽" / "好家伙" 等需慎用，仅 slice 偶发）
4. 数字直接写在 result（违反 4.4）
5. 选项动词单字（"打" / "走" / "拿"）
6. 形容词堆砌（"绝美无双的灵药" 这种）
7. "天命""主角光环""注定"等元叙述词
8. 完全无利益钩子的纯叙事事件
9. 选项之间界限模糊，玩家分不清差异

## 5. 题材灵感库

灵感清单，每写一个划掉一项。

### 5.1 生活趣事（slice）≥ 7 条

**饮食类**：
- 师妹拉你去山下小馆吃辣狐肉煲，你身上灵石只够一份，是请她还是 AA
- 集市买灵米，老板缺斤少两，是当面拆穿、当场打折、还是认栽换个摊
- 闭关久了想吃一口荤，鸡鸭灵兽都嫌寡淡，山下烧鹅摊飘香三里
- 师叔生辰宴，你两手空空，临时抓只山鸡当贺礼

**风月类**（克制处理，不下作）：
- 师兄拉你去青楼听曲，他只是听曲，但你身上没钱，他也没说要请客
- 江湖闻名的「碧水阁」女剑修途经山门，师兄们集体抢着帮她引路
- 收到一封无名情笺，落款是下山办差认识的酒馆掌柜千金，要不要回
- 同门师妹被人欺负，你帮还是不帮，帮了之后她总往你洞府跑

**闲事类**：
- 山下村民丢了灵犬，悬赏一袋灵米，要不要花一天去找
- 师兄借十灵石下月还，你想起他上次借的五块也没还
- 邻洞师弟打坐时呼噜震天，去敲门、去告状、还是搬个洞府
- 山门口卖糖葫芦的老头说他孙女病了求一颗灵草，你刚好有半株

**走亲访友**：
- 老家来信说叔父娶亲，让你下山喝喜酒，你都忘了自己还有亲戚
- 故友突然来访，住下后才发现是来借钱的
- 同乡修士遭难托孤，让你照看他十岁的女儿三月

### 5.2 师门人情（sect）≥ 5 条

- 师兄打架输了，要你帮他在师傅面前圆谎
- 师妹问你为什么修为这么慢（实则关心，主角误会成嘲讽）
- 杂役师弟偷藏了你一颗丹药，被你撞见，是揭发、要回、还是装作没看见
- 师叔考校学问，问的题你恰好不会，但隔壁师兄朝你打手势（作弊？）
- 月度宗门大会要选弟子代表上山接客，你要不要争（露脸 vs 麻烦）
- 帮师兄代值灵田一夜，第二天发现少了三株灵草

### 5.3 江湖见闻（rumor）≥ 4 条

- 茶馆听闻北山妖兽聚集，有人说是天降机缘，有人说是邪修布阵
- 坊市遇见自称是某某门派长老传人的少年，要卖你一件"祖传"法器
- 路遇一名修士求救说被仇家追杀，他可能是真的，也可能是在演
- 客栈夜宿，邻房传来低语似乎在分赃，你要不要听一听

### 5.4 战斗（combat）≤ 6 条，含 2 重要 NPC

- 「血手罗刹」拦路索买路钱（qiyun +5）
- 妖兽「九尾狐妖」吞食童子，村民集体悬赏（qiyun +3）
- 一般妖兽：野猪精、毒蛇王、化骨蝙蝠群（无 qiyun）

### 5.5 探宝（treasure）≤ 5 条

- 半启洞府、坠落仙人玉简、被禁制锁住的丹炉、坊市捡漏锈剑、深谷底古墓

## 6. Formulas

### 6.1 离开选项判定

```
if choice.get("leave", false) == true:
    # 跳过 pass_time, 跳过 complete_practice, 不应用任何字段
    _show_result(choice.result)
    _practice_active 保持 true（玩家可重新触发）
```

### 6.2 数值校验

每条事件入库前必须通过：

```
for c in event.choices:
    if c.get("leave", false):
        assert c.gold == 0 and c.prestige == 0 and c.lifespan == 0
        assert c.item == "" and c.qiyun == 0
    else:
        assert -50 <= c.gold <= 150
        assert -30 <= c.prestige <= 30
        assert -7 <= c.lifespan <= -1
        assert 0 <= c.qiyun <= 5
        assert c.cultivation == 0
        if c.item != "":
            assert c.item in ITEM_META
```

### 6.3 题材覆盖校验（按 30 事件统计）

```
combat_count <= 6
treasure_count <= 5
sect_count >= 5
rumor_count >= 4
slice_count >= 7
gray_count >= 3
重要NPC qiyun事件 == 2
```

## 7. Edge Cases

- **玩家重复选择离开**：允许。mind 不恢复，玩家无法刷出闭关收益，仅消耗少量重抽机会。
- **选项 item 已在 inventory**：`add_item` 仍 append（允许同名多份），消耗时按 `remove_item` 单次清理。
- **气运给到上限**：talent_luck 无显式上限，但突破公式 `clampf(.., 0.10, 0.95)` 自然封顶。
- **min_realm 不达门槛**：选项仍可选，应用 `low_realm_result` + `low_realm_lifespan` 作惩罚。
- **suggested_realm 与玩家境界不符**：仅影响事件触发权重（story.gd），不阻止选项可选。
- **离开选项被玩家长期忽略**：UI 不强制提示，但首选项位置已确保可见。
- **气运字段在隐藏事件中**：本期不引入，仅 adventure type 适用。

## 8. Dependencies

- **psychology-distraction.md**：mind_used / mind_max 机制；`pass_time(N)` 公式 N = ceil(mind_max/10)
- **cultivation-system.md**：talent_speed 影响 `get_speed_multiplier`，间接被功法掉落影响
- **breakthrough-minigame.md**：talent_luck 影响突破成功率（本 GDD 引入修订：`+0.02/pt` 替代原 +0.04）
- **items.gd**：所有 item 字段必须在此注册
- **player.gd**：`use_item()` 处理功法 / 气运丹永久属性增量；`add_qiyun()` helper
- **game.gd**：`_on_choice_pressed` 实现 leave 跳过 pass_time 逻辑

## 9. Tuning Knobs

| 参数 | 默认值 | 调节意义 |
|---|---|---|
| `qiyun` 单选项上限 | +5 | 调高=qiyun 累积更快，突破更顺 |
| 离开是否恢复 mind | false | 设 true 则离开变 UX 友好但可被刷 |
| 灰色选项 prestige 下限 | -15 | 调更负=灰色代价更重 |
| `talent_luck` 突破贡献系数 | 0.02 | 本 GDD 修订（原 0.04），breakthrough-minigame.md §7 反向引用此条 |
| 题材比例上下限 | 见 3.7 | 调整改变玩家体验"江湖味" |
| 功法 5 阶 talent_speed 增量 | 1/2/3/5/8 | 调高=后期修速膨胀更快 |
| 气运丹 3 阶 talent_luck 增量 | 1/2/4 | 调高=qiyun 道具更易获取 |
| 离开选项 result 模板池 | 5 套 | 增量提升离开叙事多样性 |

## 10. Acceptance Criteria

GDD 实施后必须满足以下可验证条件：

1. **schema 合规**：`story_one.gd` 所有事件首选项 `leave == true` 且数值字段全 0
2. **数值边界**：所有非 leave 选项数值在 3.4 表定义范围内
3. **道具白名单**：所有 `item` 字段引用均在 `items.gd` ITEM_META 注册（无野生 item 名）
