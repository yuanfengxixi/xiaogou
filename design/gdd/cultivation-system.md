# 修炼境界系统

## 1. Overview

境界是玩家在修仙世界的核心坐标。共六境：练气 → 筑基 → 金丹 → 元婴 → 化神 → 飞升。境界决定寿命上限、可触及的世界事件、以及与其他存在的权力差距。突破不是掷骰子——是真实的心智考验，通过技巧性小游戏完成。

## 2. Player Fantasy

- 修炼是漫长的积累，突破是命运的节点
- 突破时感受到真实的压力与专注，不是等待一个数字
- 道具和准备让玩家有策略空间，但最终靠自己
- 每次成功突破，世界向你打开新的层次
- 失败有代价，但不是终结——只是让后路更窄

## 3. Detailed Rules

### 境界表

| # | 境界 | 权力层级 | 寿命范围 | 备注 |
|---|------|---------|---------|------|
| 0 | 练气期 | 凡人层 | ~100年 | 起点，世界大多数人止步于此 |
| 1 | 筑基期 | 入门修士 | ~数百年 | 真正踏入修仙之路 |
| 2 | 金丹期 | 有成修士 | ~千年 | 一方势力中坚 |
| 3 | 元婴期 | 强者 | ~数千年 | 可主宰一方 |
| 4 | 化神期 | 顶端存在 | ~万年 | 极少数，一掌可灭宗门 |
| 5 | 飞升 | 终局 | — | 超脱此世，一局结束 |

具体寿命数值待调优，此处为量级方向。

### 修炼积累

- 玩家通过行动积累修为（闭关、历练、奇遇等方式待事件系统定义）
- 修为满后方可尝试突破
- 修为积累速度受玩家状态、专注度、外部干扰影响（详见人性/分心机制）

### 突破机制（方向）

- 突破触发条件：修为已满 + 持有对应突破材料
- 突破核心：技巧性小游戏（以舒尔特表格类为主）
- 难度随境界提升（格数更多、时限更短）
- 辅助道具：延长时限、稳定心神等（具体效果待突破小游戏GDD定义）
- 失败后果：扣寿命、消耗材料，可再次尝试但代价递增
- **基础损伤**：失败可能损伤修炼根基，导致下次同境界突破难度上升（小游戏时限缩短或格数增加）
- 损伤无上限——多次失败可能让突破趋近于不可能，贴近现实中"根基尽毁"的概念
- 损伤可修复：珍稀丹药、大能出手相助，但此类资源极度稀缺，不是常规手段
- 心态影响：连续失败可能触发负面状态（待人性机制定义）

### 权力差距

- 境界差距是绝对性的，不是数值差
- 差距超过阈值的对抗不走概率判定，直接结果
- 具体阈值见权力等级与对抗判定GDD

## 4. Formulas

突破难度曲线、修为积累速率等具体公式待子系统GDD确定。
框架层确定方向：难度递增、道具辅助、失败代价递增。

## 5. Edge Cases

- **修为已满禁止继续积累**：引导玩家突破
- **突破材料缺失**：提示获取途径，不允许裸突破（除特殊剧情外）
- **突破失败致死**：扣寿后若寿命归零，走死亡结算
- **根基尽毁**：损伤无上限，极端情况下该境界突破实际不可能完成，玩家需面对"此生止步于此"的现实
- **飞升后无后续**：realm 5 后进入终局结算，不再有任何行动
- **高境界存在突破**：世界中其他强者突破化神/飞升是世界事件，影响格局

## 6. Dependencies

- **上游**：世界时间轴（境界事件触发条件）；经济系统（突破材料来源）
- **下游**：权力等级与对抗判定（以realm为输入）；突破小游戏系统（实现突破考验）；多路线终局（飞升判定）；世界事件系统（高境界存在的世界影响）

## 7. Tuning Knobs

以下为待确定的调优维度（方向，不锁数值）：
- 各境界寿命上限
- 各境界突破材料稀缺度
- 突破小游戏难度曲线
- 失败代价递增速率
- 修为积累基础速率

## 8. Acceptance Criteria

- [ ] 六境界按顺序推进，飞升即终局
- [ ] 突破通过小游戏完成，非概率判定
- [ ] 突破失败扣寿命，材料消耗
- [ ] 境界差距超过阈值的对抗直接判定，不走概率
- [ ] 修为满后才可触发突破流程
- [ ] 飞升后进入胜利结算，无后续行动
