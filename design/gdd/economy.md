# 经济与资源系统

## 1. Overview

四大资源：**灵石**（通用货币）、**声望**（双向阵营值）、**寿命**（生命资源）、**道具**（物品）。经济系统支撑沙盒多路线玩法——长生、称霸、魔道、隐居、商贾各有各的资源路径。市场采用混合模式：宗门/块镇固定商铺保障基本需求，外出奇遇NPC商人带来稀有惊喜。家族系统已移除，所有玩家平等起点（练气期凡人），靠自己在世界中争取资源。

## 2. Player Fantasy

- 灵石有真实质感：练气期几十灵石是救命钱，化神期几千灵石视如尘土
- 买卖有发现感：稳定商铺可规划，奇遇商人让人眼前一亮
- 声望是真实站队：正道受尊崇，魔道受追杀，两极都有自己的活路
- 没有家族靠山，所有成就都是自己挣来的

## 3. Detailed Rules

### 资源定义

| 资源 | 含义 | 范围 | 特性 |
|------|------|------|------|
| 灵石 | 货币 | ≥ 0 | 不足即无法购买，不可透支 |
| 声望 | 双向阵营值 | 支持正负值 | 正邪两极各有机制 |
| 寿命 | 生命 | ≥ 0，归零死亡 | 详见修炼境界系统 |
| 道具 | 物品数组 | 允许重复 | 细分详见下文 |

### 灵石来源（沙盒多路径）

- **门派任务**：基础稳定收入
- **剧情/奇遇事件**：不定量奖励
- **战斗掉落**：对抗胜利后获取对方资源
- **劫掠**：负声望路线主要来源，有后果
- **势力分红**：所属势力定期/节日发放
- **魔道任务**：负声望解锁的高回报高风险任务
- **经商**（可选设计）：特定奇遇买低卖高

### 灵石消耗

- **固定商铺**：丹药、常规突破材料、功法
- **奇遇商人**：稀世丹药、独有宝物、情报
- **情报购买**：调查NPC/势力近况（对应世界事件系统）
- **贿赂**：打通关节、避开麻烦
- **势力贡献**：提升势力好感、换取更高权限
- **根基修复丹**：突破失败后的极稀缺资源

### 声望机制（双向设计）

**正声望**
- 正道NPC好感度提升，主动接触、提供帮助
- 正派宗门接纳门槛降低
- 正道任务解锁
- 高正声望触发特殊事件：前辈赏识、秘境邀约

**负声望**
- 正面NPC主动讨伐、正派宗门追杀
- 魔道任务解锁，高回报高风险
- 魔道势力接纳
- 高负声望触发特殊事件：魔道前辈收徒、禁地开启

**中间态**
- 无明确阵营倾向，既不受重视也不受针对
- 两极均未激活特殊机制
- 设计上让中庸反而最平淡，鼓励玩家站队

### 市场系统

**固定商铺**
- 位置：宗门内、修真块镇、散修集市
- 商品：日常丹药、常规突破材料、初阶功法
- 价格：相对稳定，不同地点略有差异
- 门槛：高阶货品可能有境界/声望/势力关系要求
- 优点：可规划、可回购、安全

**奇遇NPC商人**
- 触发：探索、游历、特定地点
- 商品：稀世宝物、特殊丹药、禁忌功法
- 价格：浮动，可能远高于市场也可能捡漏
- 特性：一次性、不可回头、不知下次何时再遇
- 风险：可能是骗子、可能是陷阱、可能真是机缘

### 道具获取渠道

| 品类 | 主要渠道 | 稀缺度 |
|------|---------|--------|
| 常规丹药 | 固定商铺 | 普通 |
| 常规突破材料 | 固定商铺 + 任务奖励 | 中等 |
| 稀有丹药 | 奇遇商人 + 任务 + 掉落 | 高 |
| 根基修复丹 | 奇遇 + 隐秘任务 + 罕见掉落 | 极高 |
| 珍稀功法 | 奇遇 + 传承 + 击败高手 | 极高 |
| 宝物装备 | 奇遇 + 劫掠 + 秘境 | 高~极高 |

### 势力关系（取代家族）

- 每个势力独立好感度（显式数值化待定）
- 所属势力：主要归属，享有资源分配、任务优先、危难庇护
- 友好势力：交易价格优惠、任务对接
- 敌对势力：拒绝交易、主动敌视
- 玩家可更换所属（有代价），也可同时与多方周旋
- 势力随世界事件兴衰，与NPC生命模拟联动

## 5. Edge Cases

- **灵石不足**：无法购买对应物品/情报，不允许透支；灵石 ≥ 0 永远成立
- **声望极端值**：正/负触顶时触发特殊事件，可能是机缘也可能是浩劫
- **势力冲突**：同时加入敌对势力不被允许，已加入情况下对方势力拒绝所有交易
- **奇遇商人欺诈**：部分商人可能出售假货或带有副作用的道具，无法完全预判
- **道具用错境界**：拒绝使用，道具不消耗

## 6. Dependencies

- **上游**：世界事件系统（事件/奇遇/商人触发）；NPC系统（势力与商人NPC定义）；门派任务系统（任务报酬来源）；修炼境界系统（境界门槛）
- **下游**：突破小游戏（突破材料、根基修复丹来源）；人性/分心机制（心志相关丹药）；多路线终局（不同路线的经济支撑）；权力系统（战斗胜负影响资源获取）

## 7. Tuning Knobs

- 各档次商品基础价格
- 境界/声望/势力门槛阈值
- 声望正/负触顶阈值
- 势力好感涨跌速率
- 奇遇商人触发概率与商品池
- 魔道任务报酬系数（应显著高于正道同等级）
- 根基修复丹稀缺度

## 8. Acceptance Criteria

- [ ] 灵石始终 ≥ 0，不足无法购买
- [ ] 声望支持负值，正/负两极各有触发机制
- [ ] 固定商铺与奇遇商人均可触达
- [ ] 高阶道具存在多条获取路径
- [ ] 势力关系取代家族，无家族系统残留
- [ ] 声望极端值触发特殊事件
- [ ] 各沙盒路线（长生/称霸/魔道/隐居）均有可行的经济路径
