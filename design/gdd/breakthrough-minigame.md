# 突破小游戏系统

## 1. Overview

突破是修仙者最重要的时刻，不是等待一个概率结果——是真实的心智考验。从小游戏池中随机抽取，境界越高难度越大、层次越多。除小游戏外，天劫、心魔、地点选择、敌人干扰等复合机制共同构成突破的完整挑战。失败损伤根基，损伤无上限，但可通过稀缺手段修复。

## 2. Player Fantasy

- 突破时真正感受到压迫感与专注，成功来自能力不是运气
- 每次尝试都是真实赌注——材料已消耗，无法反悔
- 多层挑战让每次突破都是独特的叙事事件，不只是操作关卡
- 道具和准备带来信息优势，而不是概率加成

## 3. Detailed Rules

### 突破体验设计原则

- **承诺不可撤销**：突破开始即消耗材料，无法中途放弃
- **前置叙事仪式**：小游戏前一段简短叙事（"你盘膝而坐，丹田内灵力翻涌……"），让考验在世界中发生，而非凭空弹出
- **多关卡间隙张力**：高境界连过多关时，关卡间显示进度提示（"第1关完成，灵力仍在激荡……"）
- **成功叙事回应**：突破成功后世界有反应——天地异象、寿命数字变化、周围人感知到的变化
- **准备影响信息而非概率**：道具效果是"提前知道本次抽到哪种小游戏"或"减少一个关卡"，不是概率加成
- **随机性接受**：抽取完全随机，无法干预，符合"天道不可控"世界观

### 小游戏池

突破时从池中随机抽取，玩家无法预知抽到哪种：

| 小游戏 | 核心操作 | 难度维度 |
|--------|---------|---------|
| 舒尔特表格 | 按顺序点击乱序数字 | 格数、时限 |
| 别踩白块 | 快速点击黑块避开白块 | 速度、持续时长 |
| 扫雷 | 标记地雷，不触雷完成 | 格数、地雷密度 |
| 数独 | 填满数字矩阵 | 格规模、预填数量 |
| 逻辑推理 | 根据线索推断答案 | 题目复杂度、选项干扰度 |
| （可扩展） | 后续可加入更多类型 | — |

### 抽取与组合规则（TBD）

具体境界对应抽取数量、难度参数待调优阶段确定。方向：
- 境界越低抽取数量越少，境界越高越多
- 同一小游戏在不同境界有不同难度参数
- 根基损伤累积提升当前小游戏难度参数

### 复合突破机制

小游戏之外，以下机制叠加构成完整突破挑战：

**天劫**（元婴及以上）
- 高境界突破引动天地感应，天劫降临
- 以叙事选择形式呈现：如何应对、在何处突破、是否有人护法
- 选择错误直接死亡；正确应对可获额外奖励
- 天劫强度受世界状态影响（妖兽潮期间更烈）

**心魔**（由玩家历史行为触发）
- 突破时内心映射过去的灰色选择与未竟之事
- 以文字选择形式出现，考验心志是否坚定
- 过去做过的选择越复杂，心魔越难处理
- 心魔不是随机，是玩家自己历史的回响

**突破地点**
- 灵脉之地突破有加持；战场废墟、煞气之地有干扰
- 玩家需主动选择在哪里尝试，但地点信息不完全
- 错误选择增加额外惩罚；正确选择减少关卡数或延长时限

**敌人干扰**
- 若玩家有仇家，突破进行中有概率被偷袭
- 小游戏进行到中途插入对抗判定
- 有护法者可抵御干扰；独自突破风险更高

**世界时机窗口**
- 天地异象期间突破有加持
- 妖兽潮、宗门大战期间突破有额外天劫
- 玩家需判断时机，无法精确预测世界事件

**根基完整性检验**
- 系统检验修为积累是否扎实（是否跳过必要阶段）
- 急于求成的玩家突破难度额外增加
- 体现"欲速则不达"的修仙世界逻辑

### 根基损伤机制

- 突破失败有概率损伤根基（非每次必然，但概率不低）
- 损伤体现为小游戏难度参数恶化（时限缩短或格数增加）
- 损伤无上限——多次失败后突破可能趋近不可能完成
- 修复途径：珍稀丹药、大能出手，极度稀缺，非常规手段
- 玩家可随时查看当前根基损伤状态

### 辅助道具（方向）

- **预知类**：提前知道本次抽到哪种小游戏
- **减关类**：减少本次突破关卡数量
- **延时类**：延长本次小游戏时限
- **稳心类**：降低失败时根基损伤概率
- **修复类**：恢复已损伤的根基（稀缺）
- 所有道具效果直接可感，不是概率加成

## 4. Formulas

具体数值待调优阶段确定。框架方向：
- 失败触发损伤后，下次同境界突破难度参数恶化固定量
- 损伤累积无上限
- 修复道具恢复固定量损伤

## 5. Edge Cases

- **时限归零未完成**：判定失败，进入失败结算
- **点击顺序错误**：不惩罚，仅浪费时间
- **根基严重损伤**：突破实际不可完成，玩家需先修复根基
- **天劫与小游戏同时触发**：天劫优先结算，存活后进入小游戏
- **敌人干扰时机**：插入点设计需在小游戏进行到一定程度后，给玩家足够挑战感
- **飞升特殊关卡**：机制TBD，在难度与仪式感上需超越前四次突破

## 6. Dependencies

- **上游**：修炼境界系统（realm、根基损伤状态）；经济系统（道具来源）；世界时间轴（天劫强度、时机窗口）；权力等级（敌人干扰判定）
- **下游**：修炼境界系统（突破成功后realm+1）；人性/分心机制（连续失败触发心态状态）；多路线终局（天劫死亡路线）

## 7. Tuning Knobs

- 各境界小游戏抽取数量（TBD）
- 各小游戏难度参数曲线
- 失败触发根基损伤概率
- 单次损伤量
- 天劫触发境界阈值
- 心魔触发条件（历史行为权重）
- 敌人干扰触发概率
- 化神→飞升特殊关卡形式
- talent_luck 突破贡献系数（权威源：design/gdd/story-system.md §9，当前 0.02/pt）

## 8. Acceptance Criteria

- [ ] 突破开始即消耗材料，无法中途撤销
- [ ] 突破从小游戏池随机抽取，玩家无法预知
- [ ] 各小游戏难度参数随境界递进
- [ ] 根基损伤恶化小游戏难度参数，无上限
- [ ] 修复道具可恢复损伤量
- [ ] 玩家可查看当前根基损伤状态
- [ ] 元婴及以上突破触发天劫，选择错误判定死亡
- [ ] 心魔内容反映玩家历史选择，非随机
- [ ] 地点选择影响突破难度
- [ ] 仇家存在时突破有概率被干扰
- [ ] 突破成功后世界有叙事反应
