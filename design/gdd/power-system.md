# 权力等级与对抗判定

## 1. Overview

修仙世界的权力差距是绝对的，不是数值的。境界差距超过阈值的对抗不走概率——直接判定结果。玩家没有主角光环，遭遇高境界存在和遭遇自然灾害一样，不是"很难打赢"，是"不存在打赢的可能"。

## 2. Player Fantasy

- 真实感受到修仙世界的残酷层级
- 低境界时对高境界存在的敬畏是本能，不是提示文字
- 成功躲过或周旋强者是真正的智慧体现
- 随着自身境界提升，曾经的威胁变成可对抗的存在——成长感清晰

## 3. Detailed Rules

### 对抗判定框架

对抗结果由双方**境界差距**决定：

| 境界差距 | 判定方式 | 说明 |
|---------|---------|------|
| 同境界 | 概率/选择判定 | 有博弈空间，结果不确定 |
| 差距1境界 | 严重劣势 | 胜率极低，非零但接近不可能 |
| 差距2境界及以上 | 直接判定死亡或被制 | 靠自身无法胜利也无法逃跑，外力介入除外 |

差距为对方高于玩家时适用上表；玩家高于对方时同理（玩家可单方面碾压）。

### 信息不对称

- 游戏不提供敬畏提示，不标注"此人很强"——玩家自行判断
- 对方境界通过描述、行为、周围人反应间接呈现，不直接显示数值
- 判断失误是玩家自己的决策后果，不是游戏设计失误
- 部分道具或行动可获取更明确的信息，但不会直接给出境界数字

### 非对抗性接触

高境界存在出现不一定触发对抗：
- **无视**：对方认为玩家不值一提，直接略过
- **利用**：对方将玩家作为棋子或工具
- **庇护**：对方出于某种利益或情感给予保护
- **考验**：对方以某种方式测试玩家

具体触发条件由世界事件系统决定。

### 宗门与势力

- 高境界存在的行动可影响整个势力
- 化神期存在一掌灭宗门不是剧情演出，是系统判定结果
- 玩家所在宗门被灭：失去宗门资源与庇护，可能触发逃亡事件

## 4. Formulas

具体概率与判定数值待调优。框架方向：
- 同境界对抗：选择与策略影响结果
- 差距1境界：极低胜率，具体数值待调优
- 差距2+境界：靠自身无条件死亡；外力（第三方高境界介入、特殊剧情援助）可改变结果，但不在玩家控制范围内

## 5. Edge Cases

- **隐藏高境界**：部分NPC隐藏真实境界，玩家误判导致意外死亡——正常结果，游戏不做任何"你本应知道"的提示
- **援助介入**：对抗中第三方高境界存在介入可改变结果
- **自杀性冲击**：玩家明知必死仍选择对抗，直接走死亡结算，不做额外处理
- **飞升后的存在**：已飞升者不在此世，不参与对抗判定

## 6. Dependencies

- **上游**：修炼境界系统（提供 realm 值）
- **下游**：历练事件叙事（story_one.gd / story_more.gd 事件文本可引用境界差距即死规则做剧情支撑）；多路线终局（战死路线）；人性/分心机制（面对强者时的恐惧反应）

## 7. Tuning Knobs

- 直接死亡的境界差距阈值（当前方向：2境界）
- 差距1境界时的胜率范围
- 高境界存在出现频率（由世界事件控制）
- 境界感知模糊程度

## 8. Acceptance Criteria

- [ ] 差距达阈值的对抗触发即死判定，无概率介入
- [ ] 玩家无法精确感知高境界存在的真实境界
- [ ] 化神期存在可通过系统判定摧毁宗门
- [ ] 同境界对抗存在多种结果路径
- [ ] 玩家高于对方境界时可单方面碾压
